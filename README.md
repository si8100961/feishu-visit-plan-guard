# 拜访计划安全操作

飞书多维表格侧边栏插件。原表格中打开此入口，检查计划与拜访的稳定 ID 关联，然后修改或删除。

- 空白自动预建记录：联动更新日期及客户信息；删除时先删计划，后删对应空白拜访。
- 已有内容、原始资料或关联业务：操作前选择范围；默认仅操作计划并保留历史。
- 沟通内容不被编辑操作覆盖。有关联待办或采购等记录时，不提供连同拜访删除。
- 保存和删除前重读、检查权限和变更；未知关联、多重归属、部分失败均停止，不自动重试。
- 不拦截原生右键删除、改单元格；不承诺多表事务或跨客户端强锁。
- 不需要 AI、个人访问令牌、自建后端；业务数据只经飞书 JS SDK 处理，不传第三方。
- 只在管理员明确安装「计划操作地址（系统）」入口的 Base 启用。冻结副本不自动安装。

开发：`npm ci`、`npm test`、`npm run build`。飞书托管目录 `dist`。

SDK 及 Vite 使用现有固定版本；纯前端，不包含客户数据或凭据。
